# เทสต์ A — employee ยื่นใบลาแล้วเห็นในรายการ

อ้างอิง: US-01, US-02, §6 · บัญชี: employee01 · ผลล่าสุด: ผ่าน 9/9

**ก่อนเริ่ม:** ต้องมีประเภทการลาใน Firestore (`leaveTypes`) อย่างน้อย 1 รายการ ถ้า dropdown ว่าง ให้หยุดและรายงานว่ายังไม่ได้ seed (ปัญหาข้อมูล ไม่ใช่บั๊ก)

หัวข้อที่ใช้: `[TEST] ลาทดสอบ A <วันเวลาที่รัน>` (ใส่เวลาต่อท้ายเพื่อแยกใบแต่ละรอบ)

| ขั้น | การกระทำ | คาดว่าเห็น |
|---|---|---|
| A1 | เปิด `login.html` ล็อกอิน employee01 | ไปหน้ารายการใบลา (`leave-requests.html`) ไม่ค้างหน้า login |
| A2 | เปิด `new-leave-request.html` | เห็น `#title` `#reason` `#leaveTypeId` `#startDate` `#endDate` `#ปุ่มบันทึก` และปุ่มยกเลิก |
| A3 | ดู `#leaveTypeId` | มีประเภทการลาจาก Firestore (ตามข้อมูล seed: ลาพักร้อน, ลาป่วย, ลากิจ) |
| A4 | กรอกหัวข้อ `[TEST] ลาทดสอบ A …`, เหตุผลสมมติ, เลือกประเภท, วันที่เริ่มและสิ้นสุดในอนาคต (`YYYY-MM-DD`, เริ่ม ≤ สิ้นสุด) | ไม่มีคำเตือนใน `#ข้อความเตือน` |
| A5 | กด `#ปุ่มบันทึก` | ถูกพากลับ `leave-requests.html` |
| A6 | ดูตาราง `#ผลลัพธ์` (หาแถวด้วยข้อความหัวข้อ ไม่ใช่ตำแหน่ง) | มีแถวใบที่เพิ่งยื่น ครบ 5 คอลัมน์: หัวข้อ, ประเภท, สถานะ, ผู้ขอลา, วันที่ลา |
| A7 | ดูสถานะและผู้ขอลาในแถวนั้น | ป้าย "รอพิจารณา" สีเหลือง · ผู้ขอลาเป็นชื่อที่แสดง (เช่น Tester Employee) ไม่ใช่ uid |
| A8 | คลิกแถว | เปิด `leave-request-detail.html?id=…` ข้อมูลตรงกับที่กรอก สถานะรอพิจารณา วันที่ยื่นมีค่า · **จดรหัสใบ (`id`) ไว้ให้เทสต์ B และ S2** |
| A9 | รีโหลดหน้า แล้วเปิด `leave-requests.html` ใหม่ | แถวใบนั้นยังอยู่ ข้อมูลเหมือนเดิม (ยืนยันว่าบันทึกลงฐานข้อมูลจริง) |

**ทิ้งข้อมูลไว้:** ใบ `[TEST]` 1 ใบ สถานะ `รอพิจารณา` (ลบได้ที่ปุ่มลบในหน้ารายละเอียด)
