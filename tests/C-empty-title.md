# เทสต์ C — เว้นหัวข้อ ระบบต้องไม่บันทึกและต้องขึ้นข้อความ

อ้างอิง: US-02 · บัญชี: employee01 · ผลล่าสุด: ผ่าน 6/6

**ก่อนเริ่ม:** ต้องมีประเภทการลาใน `leaveTypes` อย่างน้อย 1 รายการ · ไม่แก้ข้อมูล (ถ้าผ่าน)

| ขั้น | การกระทำ | คาดว่าเห็น |
|---|---|---|
| C1 | ล็อกอิน employee01 ไปหน้ารายการ **จดจำนวนแถวและหัวข้อที่มีอยู่** เป็นค่าก่อนเทสต์ | หน้ารายการโหลดได้ |
| C2 | เปิด `new-leave-request.html` | เห็นฟอร์ม |
| C3 | **เว้น `#title` ว่าง** กรอก `#reason` เป็นข้อความสมมติ เลือก `#leaveTypeId` กรอก `#startDate` และ `#endDate` ถูกต้อง (`YYYY-MM-DD`) | — |
| C4 | กด `#ปุ่มบันทึก` | — |
| C5 | ดูหน้าจอ | ยังอยู่ที่ `new-leave-request.html` ไม่ถูกพาไปหน้ารายการ · `#ข้อความเตือน` ขึ้น "⚠️ กรอกไม่ครบ — ต้องกรอกทุกช่องก่อนกดบันทึก" · ช่องที่กรอกไว้ยังอยู่ครบ · ปุ่มบันทึกยังกดได้ |
| C6 | ตรวจว่าไม่มีการบันทึก: ดู network ว่าไม่มีคำขอเขียน Firestore หลังกดบันทึก แล้วเปิด `leave-requests.html` | จำนวนแถวเท่าค่าก่อนเทสต์ ไม่มีใบหัวข้อว่างเพิ่ม |

**ถ้าระบบบันทึกใบหัวข้อว่างจริง = บั๊ก** รายงานชัดเจน แล้วเก็บกวาดด้วยปุ่มลบในหน้ารายละเอียด (ใบยังรอพิจารณาจึงลบได้ มี confirm) ห้ามลบผ่าน Console

**ไม่ครอบคลุม:** หัวข้อที่มีแต่ช่องว่าง, ช่องอื่นว่าง, วันที่สิ้นสุดมาก่อนวันที่เริ่ม
