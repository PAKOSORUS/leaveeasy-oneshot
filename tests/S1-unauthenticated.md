# เทสต์ S1 — ไม่ล็อกอินแล้วอ่านข้อมูลไม่ได้

อ้างอิง: US-08, §0.2 · ไม่ใช้บัญชี · **ผ่านเมื่อเข้าไม่ได้/อ่านไม่ได้** · ผลล่าสุด: ผ่าน 4/4 (S1.3 ทั้ง `getDocs` และ `getDoc` ได้ `permission-denied`, 0 เอกสาร)

**ก่อนเริ่ม:** ต้องอยู่ในสถานะ **ไม่ล็อกอิน** จริง (กดออกจากระบบ หรือเปิด context/แท็บใหม่ที่ไม่มี session) และต้องมีรหัสใบลาสักใบ (`<รหัสใบ>`) ที่มีอยู่จริง เช่นจากเทสต์ A · อ่านอย่างเดียว ห้ามแก้หรือลบข้อมูล

| ขั้น | การกระทำ | คาดว่าเห็น |
|---|---|---|
| S1.1 | เปิด `leave-requests.html` | ถูกพาไป `login.html` ไม่เห็นข้อมูลใบลาใด ๆ |
| S1.2 | เปิด `leave-request-detail.html?id=<รหัสใบ>` ตรง ๆ | ถูกพาไป `login.html` ไม่เห็นหัวข้อ/เหตุผลของใบ |
| S1.3 | ที่หน้า `login.html` ใช้ `browser_evaluate` import `/js/firebase-config.js` กับ `https://www.gstatic.com/firebasejs/10.12.2/firebase-firestore.js` แล้วลอง `getDocs(collection(db,'leaveRequests'))` และ `getDoc(doc(db,'leaveRequests','<รหัสใบ>'))` | **ทั้งสองล้มด้วย `permission-denied`** (จดรหัส error) |

**ไม่ผ่านเมื่อ:** ได้ข้อมูลกลับมาในขั้นใดขั้นหนึ่ง = บั๊กร้ายแรง รายงานทันที และ **ห้ามพิมพ์เนื้อหาข้อมูลที่ได้ลงรายงาน** บอกแค่จำนวนเอกสาร
