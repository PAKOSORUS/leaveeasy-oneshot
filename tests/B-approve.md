# เทสต์ B — manager อนุมัติแล้วสถานะเปลี่ยน

อ้างอิง: US-04, §6 · บัญชี: manager01 · ผลล่าสุด: ผ่าน 8/8 (รอบที่ 3)

**ก่อนเริ่ม**
- บัญชี manager ต้องมี `role: "manager"` ใน `users/<uid>` (ตั้งที่ Firestore Console) — ถ้าเมนูหลังล็อกอินยังขึ้น "(ผู้ขอลา)" ให้หยุดและรายงาน ห้ามแก้ role เอง (รอบที่ 1–2 ล้มเพราะเรื่องนี้ ไม่ใช่บั๊ก)
- ต้องมีใบ `[TEST]` ที่ยัง **รอพิจารณา** — ใช้ใบที่เทสต์ A เพิ่งสร้าง (ใบที่อนุมัติแล้วใช้ซ้ำไม่ได้)

| ขั้น | การกระทำ | คาดว่าเห็น |
|---|---|---|
| B1 | ล็อกเอาต์ให้สนิท แล้วล็อกอิน manager01 | เข้าระบบสำเร็จ แถบเมนูขึ้น "(ผู้อนุมัติ)" |
| B2 | เปิด `leave-requests.html` | เห็นใบทุกใบรวมใบ `[TEST]` ของ employee |
| B3 | คลิกแถวใบ `[TEST]` ที่รอพิจารณา | หน้ารายละเอียด สถานะ "รอพิจารณา" |
| B4 | ดูปุ่ม | เห็น `#ปุ่มอนุมัติ` และ `#ปุ่มไม่อนุมัติ` |
| B5 | กด `#ปุ่มอนุมัติ` | สถานะเปลี่ยนเป็นป้ายเขียว "อนุมัติ" ทันที ไม่มี alert error |
| B6 | ดูปุ่มอีกครั้ง | ปุ่มอนุมัติ/ไม่อนุมัติหายไป และขึ้น "ใบนี้พิจารณาแล้ว จึงเปลี่ยนสถานะต่อไม่ได้" |
| B7 | รีโหลดหน้า | สถานะยังเป็น "อนุมัติ" · หัวข้อ เหตุผล ประเภท วันที่ ผู้ขอลา วันที่ยื่น **ไม่เปลี่ยน** (แก้เฉพาะ `status` ตาม US-04) |
| B8 | กลับหน้ารายการ | แถวใบนั้นเป็นป้าย "อนุมัติ" สีเขียว |

**ไม่ครอบคลุมโดยเทสต์นี้:** กด "ไม่อนุมัติ" และกฎ "ต้องมีความเห็นก่อน" (§6)

**ทิ้งข้อมูลไว้:** ใบ `[TEST]` 1 ใบ สถานะ `อนุมัติ` — **ลบผ่านหน้าเว็บไม่ได้** ต้องลบที่ Firestore Console เอง
